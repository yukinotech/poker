# ♠ ♥ ♦ ♣ Poker CLI

一个简洁、零依赖的单机 Texas Hold'em 命令行游戏。你将与多个会根据牌力、听牌和底池赔率做决策的 CPU 对战。

## 功能

- 标准 52 张牌，显示 `♠ ♥ ♦ ♣` 花色及牌面大小
- 翻牌前、翻牌、转牌、河牌与摊牌完整流程
- 支持过牌、下注、跟注、加注、再加注、弃牌和全下
- 完整识别高牌至同花顺的所有牌型
- 默认 4 人桌，可设置 1–5 个 CPU 对手，支持多人主池与边池结算
- 默认每人 2000 筹码，采用 10/20 小盲与大盲，庄位和盲位逐手轮转
- CPU 采用混合策略：强牌价值下注、弱牌/听牌选择性诈唬，中等牌控制底池
- 不同 CPU 有不同激进度和诈唬频率，并会根据多人底池收紧价值范围
- 无限注规则，可自由输入下注或加注尺度
- 每次决策都会重显手牌、公共牌、实时底池、筹码、当前牌力与底池赔率
- 每个 CPU 的过牌、下注、跟注、加注和弃牌都会按行动顺序单独显示
- 手牌与公共牌每条街只展示一次，决策时仅刷新底池、筹码和赔率

## 运行

需要 Python 3.10 或更高版本，无需第三方依赖：

```bash
python3 -m poker
```

也可以安装为命令：

```bash
python3 -m pip install -e .
poker
```

可选参数：

```bash
poker --chips 5000      # 设置每位玩家的初始筹码（默认 2000）
poker --opponents 5     # 与 5 个 CPU 对战（支持 1–5）
poker --seed 42         # 固定发牌结果，便于复现
```

游戏中的操作命令：

```text
c       过牌或跟注
b 60    下注到 60
r 120   加注到本条街总额 120
f       弃牌
a       全下
```

只输入 `b` 或 `r` 时，游戏会继续询问目标金额。每手结束后按 Enter 继续，输入 `q` 离开。

## 规则简化

这是多人无限注版本：盲注级别为 10/20，翻牌前从大盲左侧开始行动；翻牌后从庄家左侧开始。最小下注为 20，最小加注量等于上一注的增量；下注上限为玩家的全部剩余筹码。多人可以连续加注，筹码不足时可以全下，并按各玩家投入正确拆分主池与边池。
